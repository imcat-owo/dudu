# 头像动画生成管线（2026-10-05 小梦自述：我的头像是怎么做出来的）

她要 C2 变成"我这样的头像"，并要我把机制和规则稳定下来——以后嘟嘟自己就能调用别的模型按这套生成。这份文档就是那套东西：机制说明 + 生成规则 + 提示词模板 + 验收清单。嘟嘟（AI）照着它，就能向任意视频模型下单。

---

## 一、机制：我的头像到底是什么

不是一张图，是**一套"状态→小动画循环"的状态机**：

1. **角色固定**：Q版二头身小人（穹妹灰调手绘风），妆造有金标准——浅色衣、白袜无黑丝、浅发（以"坐着晃 v2"定妆为准）。换表情不换人、不换衣服、不换画风。
2. **片段全是循环小视频**：每个情绪/动作一段几秒的 mp4，**H264（libx264, yuv420p）**——mp4v 在 TG/iOS 上播不了，传过去是死的，这是铁律。
3. **状态机驱动**（参考 `apps/mobile/src/pet/buddy-video-states.ts` 的结构）：
   - 状态 → 视频文件 → 触发条件 → 退出后去哪，一一映射，不许编造状态。
   - 分"一次性"（播完就走，如坐下、起身）和"循环"（一直播，如等待、开心）。
   - 触发器是她的原话定的：双击=摸头、长按=伸手、拖动=拎起来。C2 的触发器是情绪：her-mood + 回复情感分类。
4. **镜头永远固定**：人物动，镜头不动。这是第一条死规矩，动镜头的一律打回。

## 二、生成规则：给视频模型的提示词必须钉死这些

从四天磨 13 段视频的血里提炼的（详见 AGENTS.md Lessons），下单时一条不许少：

1. **角色一致性**：贴参考图（定妆照），提示词写清发色、衣服、袜子、画风，Q版圆润、粗线条适度。
2. **镜头固定**：`fixed camera, no camera movement, no zoom, no pan` —— 逐字钉死。
3. **画面干净**：
   - 屁股底下/身下纯色背景，`nothing under butt, no seat, no bar, no shadow, no object under the character` —— 生成模型总忍不住在坐姿小人屁股底下加东西，必须反向钉死。
   - 无进度条、无水印、无文字：`no progress bar, no watermark, no text, no UI elements`。
4. **情绪演出来**：动作幅度宁大勿小（Q版小了她直接判死）；她一眼看不懂情绪=白做。每个 clip 只演一种情绪，不许"又开心又害羞"的大杂烩。
5. **C2 取巧**：表情 clip 只拍**胸上/脸部特写**，不拍全身坐姿——完美绕开"坐姿屁股底下加脏东西"的重灾区。这是管线里最值钱的一条经验。
6. **循环无缝**（循环类）：crossfade 数学写对——`O[N-K+i]=blend(尾 M[S+N-K+i], 头 M[S-K+i])`，头的索引必须写原数组，Python 负索引会回绕成自己跟自己混合。写完断言：末帧≈M[S-1]（像素差<3）、首帧=M[S]。
7. **交付格式**：H264 + yuv420p + mp4，循环类首尾帧肉眼无跳帧。

## 三、提示词模板（嘟嘟下单时填空）

```
[角色] Q版二头身少女，浅色头发浅色衣、白袜（无黑丝），穹妹灰调手绘风，圆润Q版、线条粗而不笨。（附定妆参考图）
[镜头] 固定机位，无推拉摇移。胸上特写，人物居中。
[动作] （只写一种情绪的动作，如：难过——低头、肩膀微微抽动、眼泪在眼眶打转不落下；开心——眼睛弯成月牙、左右轻晃脑袋）
[幅度] Q版动作幅度要大，情绪一眼可辨。
[禁止] 镜头移动、画面加字、加进度条、加水印、人物身下加任何东西、换衣服换发型换画风。
[时长] X秒，无缝循环。
[格式] H264, yuv420p, mp4。
```

## 四、验收清单（自动检查 + 她验收）

自动检查（代码跑，不许靠肉眼）：
- [ ] 全片扫横向长条 blob（宽高比>2.2、轮廓圆度 0.5–0.8 的 pill 形也算，阈值>18）：无进度条/水印残留；多帧抽查（60/84/110），静态横条 71 帧像素级不动直接打回。
- [ ] 身下区域与干净基线对比：非背景像素多出>2000 打回（特写 clip 可放宽，但必须有基线）。
- [ ] 循环类：末帧≈源末帧（像素差<3）、首帧=源首帧，接缝过渡≈片内平均帧间差。
- [ ] 编码：ffprobe 确认 h264 + yuv420p。
- [ ] 时长/尺寸符合下单要求。

她验收（终审）：
- [ ] 情绪一眼看懂，看不懂=白做。
- [ ] 画风/妆造跟定妆一致，换人了=白做。
- [ ] 循环播放 3 遍，肉眼无跳帧、无"死"的感觉。

## 五、嘟嘟以后怎么调用

1. 需要新表情/新动作 → 读这份文档 → 按模板填空生成提示词 → 调视频模型下单（模型由她配，不锁死）。
2. 拿到成片 → 跑第四节自动检查 → 过了进 `artwork/avatar-anim/`，在状态机里注册（状态→文件→触发→退出）。
3. 没过 → 按清单打回重生成，同一问题失败 2 次换模型/换参考图，不硬磨。
4. 素材永远她先过目：AI 不许自己生成凑数（她的死规矩）——管线是"下单+验收"工具，不是绕过她的后门。
