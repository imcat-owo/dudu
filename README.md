**要爱给爱，要能力给能力。**

## 功能

### 陪伴

| 功能 | 说明 |
|---|---|
| 我们的空间 | 双人头像、动态流（双向发帖/点赞/评论）、纪念日、作品抽屉（AI 做的图、HTML、主题、文件） |
| 记忆花园 | AI 记得什么、拿不准什么、想问你的——看得见，删得掉；另有图谱视图看记忆关联 |
| AI 自发帖 | AI 会自己发动态（有内容才发，不编） |
| 次日跟进 | 昨天聊的事，第二天 AI 会提起 |
| 每日心情打卡 | 每天问一次心情，难熬的日子它记得 |
| 性格进化 | 处得久了，AI 的性格会变 |
| 人格维度滑杆 | 五维人格可调 |
| 互动故事 | AI 主导的选择式剧情 |
| 轻游戏化 | 在一起纪念日庆祝、互送小礼物（克制版） |
| 分段发送 | 长回复拆成几条短消息，像真人打字 |
| 照片涂鸦 | 你发照片，AI 能在上面涂鸦回应 |
| 图片表情包 | 自建表情包（自己传图），AI 也能发 |
| AI 主动发照片 | AI 偶尔发自拍（默认关，睡眠时间不打扰） |
| 情书 | 纪念日、难过的时候，AI 写一封收在空间里 |
| 我的日记 | AI 用自己的语气写日记 |
| 稍后告诉她 | AI 想说还没说的先存着，有由头再告诉你 |

### 聊天与语音

- 多模型 / API 分组：URL、key、模型名自己配，随时切换；key 不进仓库
- 智能 API 自适应：能力探测、失败分类、自动降级重试（默认全开，实测不行才降级）
- 流式输出、工具调用、分支对话、Artifacts 预览、thinking 抽屉
- 实时双工语音通话；情绪化 TTS（语气随内容变）；TTS/STT 可自定义接第三方
- 微信式语音气泡

### AI 的手

- AI 浏览器：导航、点击、输入、截图（对照 OpenMinis 的浏览器自动化做的）
- 沙箱：云服务器 / 本地仿 iSH 双后端，可切换
- MCP 工具池（含审批卡片）、知识库（文档上传 + 向量检索）
- 原生应用授权：Apple Music、HealthKit、日历/提醒事项等，iOS 允许的第三方能力逐个接
- 纸条机制：聊到相关话题，系统给 AI 塞小纸条说明书；用过一次不再重复注入

### 外观

- AI 换肤（16 个工具，先试穿后存档）、主题包导入导出（JSON/二维码/系统分享）、字体上传
- 默认穹妹灰调手绘风，深色模式单独设计；外观跟随 iOS 系统设置
- 头像自定义：AI 可改，你也可改

## 隐私

- 默认纯客户端：key 配在 App 里，聊天从手机直连模型，数据存手机本地
- 隐身聊天：退出即销毁，服务端不留痕
- 备份恢复：`dudu.*` 数据可导出、带走、恢复
- 权限用时才申请：相册、定位、麦克风、通知等

云模式是可选的，两套随时切换。聊天记录只在你的手机上。

## 开发

```bash
# 依赖
pnpm install

# 跑测试
pnpm test

# 类型检查
pnpm -C apps/mobile exec tsc --noEmit

# lint
pnpm -C apps/mobile exec biome check .
```

目标平台：iOS 26。构建走 GitHub Actions（`.github/workflows/build-ios.yml`）。
